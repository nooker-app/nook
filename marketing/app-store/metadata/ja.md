# Japanese

アプリ名は四つのロケールで同じにします。ブランドが一つに読めますし、ストアごとに違う名前が
出ると同じアプリか確かめる手間が生まれます。サブタイトル以下はすべて現地化します。

## App Name (22/30)

```text
Nook: Read, Write, Own
```

## Subtitle (20/30)

```text
オフラインで読むRSSリーダー、書く場所
```

名前が持っていない検索語をサブタイトルが引き受けます。「オフライン」が先なのは、それが
他のリーダーと分かれる点で、しかも誇張ではないからです。ネットワークもアカウントもなしに
開いて読めます。

## Promotional Text (69/170)

ビルドなしで差し替えられる欄なので、いま事実であることだけを置きます。

```text
Nookはフィードをこの端末で読みます。アカウントもアルゴリズムもありません。記事の公開はベータで、招待されたアカウントに開かれています。
```

## Keywords (56/100)

```text
rss,atom,フィード,ニュース,オフライン,opml,翻訳,マークダウン,ブログ,公開,購読,スター,読書
```

競合アプリの名前は入れません。他社の商標をキーワードに書くと、順位ではなく審査で止まります。

## Description (1150/4000)

```text
Nookは、何を読むかを自分で選びたい人のためのRSSリーダーです。

フィードのアドレスを入れるか、ウェブサイトのアドレスを貼るだけでNookがフィードを見つけます。購読リスト、既読、スターはこの端末にあります。作るアカウントはなく、何を読んだかはどこにも送られません。

邪魔をしないリーダー

記事はネイティブに描かれます。ウェブページを画面に押し込むのではなく、きちんと組みます。見出し、引用、コード、表、入れ子のリスト、画像、動画が構造をそのまま保ちます。フォント、サイズ、行間、字間、色を変えられますし、元のレイアウトが惜しいフィードだけを全ページのリーダーか元のサイトに切り替えられます。

ネットワークがなくても

Nookはオフラインに対応しているのではなく、オフラインを前提に作られています。接続がなくても起動し、一覧が出て、読めます。後で読む記事を選んで保存し、いつ期限切れにするかも決められます。

アカウントのいらない同期

iCloud DriveやDropboxのようにファイルを同期するフォルダを指定すると、フィード、既読、スター、カテゴリ、フォルダが端末の間を追いかけます。ファイルを運ぶのはそのサービスで、まとめるのはNookが端末ごとに行います。二台を同時に変更しても互いを上書きしません。私たちのサーバーは関与しません。存在しないからです。

翻訳は自分の決めた形で

記事全体を訳すことも、一覧のタイトルだけを訳すこともできます。Apple Intelligenceは端末の中で動き、費用はかかりません。Geminiは自分でオンにする方式で、発行したAPIキーをこの端末のキーチェーンに保管します。同期フォルダには入れません。

考えるとおりに整理

フィードはフォルダで、記事は色のついたカテゴリでまとめます。キーワードのルールとテキストフィルタがあり、除いた記事は削除せず別に集めます。新しい記事を主題ごとに分ける作業はApple IntelligenceかGeminiに任せられます。

既定は静かであること

広告も、追跡も、分析も、引き留める仕掛けもありません。バッジと新着通知は切れた状態で始まり、権限はその設定をオンにした後で初めて尋ねます。起動時には尋ねません。

公開（ベータ、招待制）

Nookは書いた記事を公開することもできます。記事は利用者自身のAT Protocolリポジトリにレコードとして保存され、他の人が購読できる本物のフィードを備えたウェブページとして提供されます。すべてのレコードをいつでも書き出して削除できます。公開が停止されている間もそうです。この部分はベータで招待が必要です。ここまでのすべては招待なしで動きます。
```

## URLs

ロケールに関係なく同じです。サイトは英語の一組だけで、訳されたページを指すふりをするより、
あるままにしておくほうがましです。

```text
Support URL:        https://www.nooker.app/support/
Marketing URL:      https://www.nooker.app/
Privacy Policy URL: https://www.nooker.app/privacy/
```

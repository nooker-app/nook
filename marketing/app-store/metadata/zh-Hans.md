# Simplified Chinese

应用名称在四个语言下保持一致。品牌读起来是一个，各地商店出现不同名字反而要让人确认是否同一个
应用。副标题以下全部本地化。

## App Name (22/30)

```text
Nook: Read, Write, Own
```

## Subtitle (18/30)

```text
离线优先的 RSS 阅读器，也能写作
```

名称没有承担的搜索词由副标题接过来。"离线优先"放在最前，因为这是它与多数阅读器分开的地方，
而且不是夸张：没有网络、没有账号也能打开和阅读。

## Promotional Text (49/170)

不用发版就能改的字段，所以只放当下确实成立的内容。

```text
Nook 在本机读你的订阅源，没有账号，也没有算法。发布自己的文章处于测试阶段，面向受邀账号开放。
```

## Keywords (50/100)

```text
rss,atom,订阅源,新闻,离线,opml,翻译,markdown,博客,发布,订阅,收藏,阅读
```

不放竞品名称。把别家的商标写进关键词，拦住的是审核，不是排名。

## Description (888/4000)

```text
Nook 是给那些愿意自己决定读什么的人做的 RSS 阅读器。

填入订阅源地址，或者只粘贴网站地址，Nook 会把订阅源找出来。订阅列表、已读标记和收藏都在这台设备上。没有要注册的账号，读过什么也不会发往任何地方。

一个让开的阅读器

文章以原生方式绘制，不是把网页塞进屏幕，而是认真排版。标题、引用、代码、表格、嵌套列表、图片和视频都保持原有结构。字体、字号、行距、字距和颜色都能改；如果某个订阅源原本的版式值得保留，可以只把那一个切换成整页阅读器或原始网页。

没有网络也可以

Nook 不是支持离线，而是以离线为前提做的。没有连接也能启动、列出、阅读。可以挑出以后再读的文章保存下来，并决定什么时候过期。

不需要账号的同步

指向 iCloud Drive、Dropbox 或任何会同步文件的文件夹，订阅源、已读、收藏、分类和文件夹就会跟着你在设备之间走。搬运文件的是那个服务，合并的是 Nook，按设备分别进行。两台设备同时改动也不会互相覆盖。我们的服务器不参与，因为并不存在。

翻译按你定的方式来

可以翻译整篇文章，也可以只翻译列表里的标题。Apple Intelligence 在设备内运行，不产生费用。Gemini 需要自己开启，用你申请的 API 密钥，保存在这台设备的钥匙串里，不会放进同步文件夹。

按你思考的方式整理

订阅源用文件夹，文章用带颜色的分类。有关键词规则和文本筛选，被滤掉的文章不删除，而是另外收着。给新文章按主题归类这件事，可以交给 Apple Intelligence 或 Gemini。

默认是安静的

没有广告、没有追踪、没有分析，也没有留住你的机制。角标和新文章通知一开始是关的，只有在你打开某项设置之后才会请求权限，启动时不会问。

发布（测试阶段，仅限受邀）

Nook 也可以发布你写的文章。文章作为记录保存在属于你的 AT Protocol 仓库里，并以网页形式提供，附带别人可以订阅的真实订阅源。你可以随时导出全部记录并删除，即使发布被暂停也一样。这部分处于测试阶段，需要邀请。上面的一切不需要邀请就能用。
```

## URLs

与语言无关，都相同。网站只有英文一套；与其假装指向已翻译的页面，不如照实放着。

```text
Support URL:        https://www.nooker.app/support/
Marketing URL:      https://www.nooker.app/
Privacy Policy URL: https://www.nooker.app/privacy/
```
